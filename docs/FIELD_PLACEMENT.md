# 위드싸인 템플릿 필드 배치 가이드

위드싸인은 템플릿 업로드·필드배치를 API로 지원하지 않습니다 — 대시보드에서 직접 해야 합니다. 필드를 놓을 때 **누가 그 필드를 채우는지(발신자/수신자)** 를 정확히 구분하는 게 핵심입니다.

## 발신자 필드 (Notion에서 값을 가져와 발송 시 자동으로 채움)

계약마다 값이 바뀌지만, 발송하는 쪽(나)이 이미 알고 있는 정보. 예: 계약명, 계약기간, 계약금액, 작성일자, 프로젝트명, 일정, 장소.

위드싸인 필드배치 화면에서 이 필드들의 "담당자"를 **발신자**로 지정합니다 (내부적으로 `group_num: 0`).

## 수신자 필드 (서명 중 상대방이 직접 입력)

발신자가 미리 알 수 없거나, 개인정보라 상대방이 직접 입력해야 하는 정보. 예: 계약상대자명, 주소, 대표자명, 입금 계좌 정보.

이 필드들의 담당자를 **수신자**로 지정합니다 (`group_num: 1`). 완료 후 `widsignReceiverInputValues` / `widsignSyncCompletedDocument`가 이 값들을 Notion으로 자동 회수합니다.

## 같은 내용이 문서 여러 곳에 나오는 경우

계약상대자명이 표지·본문·서명란 등 여러 곳에 인쇄되는 경우, 위드싸인 필드배치에서는 각 위치마다 별도 필드로 배치해야 합니다 (같은 이름을 여러 번 써도 무방 — id로 구분됨). `fieldMapping.ts`에서 하나의 Notion 속성에 여러 item id를 배열로 매핑하면, 발송/회수 시 자동으로 모든 위치에 동일한 값이 반영됩니다.

```ts
계약상대자: [
  "6a9684d1...",  // 표지
  "6a96850a...",  // 본문 제1조
  "6a96859d...",  // 개인정보 동의서
],
```

## 필드 ID 확인 방법

템플릿 업로드·필드배치가 끝나면, 배포된 Worker에서 아래 tool로 각 필드의 id·type·group_num을 확인할 수 있습니다.

```bash
ntn workers exec widsignTemplateDetail -d '{"form_id": "<템플릿 ID>"}'
```

필드 이름이 "텍스트1"처럼 라벨이 없어 헷갈리면, `x`/`y` 좌표와 실제 계약서 배경 이미지(`background.url`)를 대조해서 어떤 내용인지 눈으로 확인하세요.
